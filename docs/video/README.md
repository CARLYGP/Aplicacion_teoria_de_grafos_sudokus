# Video del README (Remotion)

Proyecto [Remotion](https://www.remotion.dev/) que arma el video y las portadas del README con datos reales del repositorio.

```bash
npm install
npx remotion studio      # vista previa interactiva
npx remotion render      # exporta el video
```

Los datos se generan con el script de Python de esta carpeta; las instrucciones completas están en el README principal.
